# tonal-fixtures (private mirror)

Audio + annotation mirror for the Tonal app's external onset/
articulation benchmarks. Lives next to `tonal/` so the Dart test
harness can resolve `../tonal-fixtures/{corpus}/...` relatively.

**This repo stays private.** Each subfolder mirrors a corpus with
its own license — see `tonal/docs/decisions/0017-public-trumpet-corpora.md`
for the full audit.

## Layout

```
phenicx/   PHENICX-Anechoic trumpet section mixes + annotations.
           Source: github.com/MTG/phenicx-anechoic, non-commercial.
           Generated by tonal/tools/corpora/phenicx_download.py +
           phenicx_to_fixture_annotations.py.
```

## Reproduction

The Tonal scripts under `tonal/tools/corpora/` are idempotent.
Re-running them rebuilds the contents of this mirror from the
upstream corpora; this repo is a cache, not the source of truth.
